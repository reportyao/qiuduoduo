# 球多多 AI-native 重构：一个助理，三个脑，按 Token 付费（2026-11-12）

> **已作废（2026-11-12）**：以 [qiuduoduo-v4-final-plan.md](./qiuduoduo-v4-final-plan.md) 为唯一有效方案。本文仅作历史参考。

> 上一版“AI 分析员团队 + 金币”是传统互联网的 IP 化思路：把 AI 包装成专家、再造一套虚拟货币。它和“一个 AI 助理”的产品逻辑冲突，也不像 AI 时代的产品。
>
> 这一版换底层：**不卖专家，卖思考；不发金币，消耗 Token；不增加助理，给同一个助理三个脑。**

## 一、核心判断

AI 时代的产品，付费单位不应该是“解锁一条内容”，而应该是“让 AI 想多深”。

用户不是在买“某个专家的一场推荐”，而是在买：

- 让助理帮我快速看一眼；
- 让助理认真算一场；
- 让助理开三个脑互相吵一架；
- 让助理帮我盯着这场，开赛前自动再算一次。

这四件事消耗的 Token 不一样，价值也不一样。**Token 就是产品天然的计量单位，不需要再造金币。**

## 二、一个助理，三个脑

不新增“AI 分析员”人格，也不做专家列表。仍然是现在这一个 AI 助理，但它有三种思考模式：

| 脑 | 角色 | 回答风格 | 适合问题 |
|---|---|---|---|
| **数据脑** | 概率/模型 | “主胜 74%，模型与市场分歧 12pp” | 这场概率怎么样？ |
| **市场脑** | 盘口/聪明钱 | “市场只给 62%，价值一般” | 市场怎么看？ |
| **冷门脑** | 高赔/反共识 | “不碰，风险太大；如果搏，只能小注” | 有没有冷门？ |

用户看到的是：

> “我让三个脑分别看了一眼，它们吵起来了。数据脑说主胜，市场脑说价值不够，冷门脑说别碰。我的结论是：观望。”

这不是三个人，是**同一个助理的三种思考方式**。逻辑不冲突，风险归因仍然存在：数据脑错了，用户可以“换市场脑再看一遍”，但助理还是同一个。

### 三脑的战绩

- 每个脑有自己的历史表现：命中率、Brier、CLV、连红/连黑；
- 战绩来自真实结算，不是专家自报；
- 用户可以看到“数据脑近 30 天更稳，市场脑在冷门场更准”；
- 不伪装真人，不编造“1.78w 人看过”。

## 三、四种交互，四种 Token 消耗

### 1. 快问（免费/极低 Token）

- “这场怎么看？”
- 回答一句话：方向 + 概率 + 一句理由。
- 免费额度内不扣或扣极少 Token。
- 目的：让用户先开口，建立习惯。

### 2. 深算（核心付费）

- 用户点“深算这场”，助理给出：
  - 结论、概率区间、期望回报
  - 三条关键依据
  - 两条风险
  - 失效条件
  - 数据截止时间
- 页面上明确显示：`本次深算预计消耗 6,000–8,000 tokens`。
- 结果 30 分钟内追问免费。
- 目的：把“认真算一场”变成可感知的消费。

### 3. 三脑圆桌（高价值/高 Token）

- 助理同时跑数据脑、市场脑、冷门脑，最后合成结论。
- 输出一张可分享的“三脑分歧卡”：
  - 数据脑：主胜 74%
  - 市场脑：主胜但价值不足
  - 冷门脑：不建议
  - 助理结论：观望/小注/主推
- 消耗约 3–5 倍深算 Token。
- 目的：制造“AI 内部吵架”的戏剧性，适合分享和传播。

### 4. 自动盯盘（订阅 + Token）

- 用户关注一场，助理在 T-2h / T-30min 自动深算一次。
- 阵容、赔率、情报变化时推送。
- 订阅包含每月 Token 配额；超出按量。
- 目的：从“一次提问”变成“持续服务”。

## 四、Token 体系：不是金币

### 4.1 免费额度

- 每日赠送固定 Token（例如 20,000）；
- 够 1 次深算 + 若干快问；
- 每日 00:00 重置，未用完不累积（或少量累积，制造使用紧迫感）；
- 首页显示：`今日免费算力 20,000 · 剩余 12,400`。

### 4.2 Token 包

| 商品 | Token | 价格（示例） |
|---|---|---|
| 体验包 | 100,000 | ¥12 |
| 常用包 | 500,000 | ¥48 |
| 赛季包 | 2,000,000 | ¥168 |
| 深算会员 | 1,000,000/月 | ¥68/月 |

价格按实际模型成本 + 产品价值定，不按“金币”虚构汇率。

### 4.3 计费规则

- 快问：免费额度内不扣；
- 深算：按实际 input/output tokens 扣，失败不扣；
- 圆桌：3 个脑 + 合成，按实际扣；
- 自动盯盘：订阅配额优先，超出按量；
- 同一场比赛 30 分钟内重复深算，走缓存，不重复扣；
- 每次操作前显示预估区间，结束后显示实际消耗。

### 4.4 为什么 Token 比金币好

- **真实**：用户知道 AI 思考有成本，不是虚拟货币游戏；
- **可解释**：深度不同、Token 不同，价格有依据；
- **可扩展**：以后加语音、图片、视频分析，仍然按 Token；
- **不冲突**：不需要“专家订阅”，只需要“算力额度”；
- **AI-native**：产品语言统一为“算力/思考/深算”，不是“吧币/金币”。

- 三脑分歧榜（数据脑/市场脑/冷门脑结论不一致的场次）；
- “AI 正在算”队列（真实任务，不伪造）。

这不是专家榜，是**AI 算力热度榜**，更符合 AI 产品气质。

## 六、后端设计

### 6.1 Token 账户

```text
token_accounts
  user_id, balance, daily_free_grant, daily_used, last_grant_date,
  membership_expires_at, updated_at

token_ledger
  id, user_id, amount, type(free_grant/deep/roundtable/monitor/purchase/refund),
  reference_id, input_tokens, output_tokens, cost_cny, created_at
```

复用现有 `llm_usage`：每次 AI 调用已有 token/成本记录，新增 `user_id` / `run_id` / `task` 关联。

### 6.2 AI 任务表

```text
ai_runs
  id, user_id, match_id, task(quick/deep/roundtable/monitor),
  status, prompt_hash, input_tokens, output_tokens, cost_cny,
  result_json, error, created_at, expires_at
```

### 6.3 三脑

不是三个独立 Agent，而是 `roundtable` 任务内部的三个提示模板 + 一个合成模板：

```text
data_brain: 只基于模型/概率/数据
market_brain: 只基于盘口/市场分歧
contrarian_brain: 只基于高赔/反共识
synthesizer: 综合三者，输出结论/分歧/风险
```

每个脑的输出都带自己的依据；合成器不编造，只归纳。

### 6.4 API

```text
GET  /ai/balance
POST /ai/estimate          # 预估某场深算/圆桌 token
POST /ai/quick             # 快问
POST /ai/deep              # 深算
POST /ai/roundtable        # 三脑圆桌
POST /ai/follow-up         # 30 分钟内追问，免费/低价
GET  /ai/runs              # 历史
POST /ai/monitor           # 自动盯盘订阅
GET  /ai/heat              # 算力广场聚合
GET  /tokens/packs
POST /tokens/purchase
POST /tokens/checkin       # 签到送 token
```

### 6.5 计费流程

1. 估算 Token 区间；
2. 检查余额/免费额度；
3. 不足 → 引导充值/会员，不阻断快问；
4. 执行 LLM；
5. 按实际 usage 扣费；
6. 失败/超时 → 全额退回；
7. 写 ledger + ai_runs；
8. 结果缓存 30 分钟，重复追问不重复扣。

### 6.6 自动盯盘

- 用户关注比赛 → 创建 monitor task；
- T-2h、T-30min 各跑一次深算；
- 有阵容/赔率变化时额外触发；
- 订阅配额优先，超出按量；
- 推送只写“AI 已更新这场判断”，不写赔率/结果。

## 七、商业化与增长

### 7.1 付费触发点

- 免费额度剩余 20% 提示；
- 深算按钮显示预计 Token；
- 圆桌按钮显示“3 个脑 · 18k tokens”；
- 赛前 30 分钟：“你关注的比赛要开了，AI 还没深算”；
- 三脑分歧卡分享 → 好友点开也要算；
- 签到/连续深算送 Token。

### 7.2 心理杠杆

| 杠杆 | 用法 |
|---|---|
| 稀缺 | 每日免费 Token 有限，当日重置 |
| 好奇 | 三脑分歧卡：“三个脑吵起来了” |
| 社会证明 | 真实深算次数、最热场 |
| 损失厌恶 | 关注场开赛前未深算提醒 |
| 沉没成本 | 已购 Token、连续深算天数 |
| 互惠 | 深算后 30 分钟追问免费 |
| 锚定 | Token 包/会员梯度 |
| 权威 | 三脑战绩、可复算数据 |
| 完成欲 | 每日 1 场深算挑战 |

### 7.3 留存

- 助理记忆：记住用户关注的队、风险偏好、常看联赛；
- 自动盯盘：把“打开 App”变成“助理主动找我”；
- 昨日复盘：AI 解释错在哪；
- 连续深算：7 天/30 天挑战，送 Token；
- 分享三脑卡：社交裂变。

## 十、边界

1. 不伪装真人专家，三脑明确是 AI 思考模式；
2. 不承诺收益，不写“稳赚/必中/包赔”；
3. Token 消耗必须可解释、可退款（失败退回）；
4. 免费快问不能被砍，否则变成纯付费墙；
5. 年龄/自排除/连败保护保留；
6. 热度数据必须真实，不刷“多少人看过”。

## 十一、一句话

**竞品卖的是“专家结论”，我们卖的是“AI 思考的深度”。**
一个助理，三个脑，按 Token 付费；用户为“想得更深”买单，而不是为“某个专家”买单。
