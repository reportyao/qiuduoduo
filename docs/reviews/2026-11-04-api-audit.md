# API 全量审查与补全记录（2026-11-04）

> **历史快照（2026-11-04）**：本文的测试数/路径数/结论反映当时状态，不是当前事实。当前事实见 [docs/README.md](../README.md)：265 tests / 128 路径 / 143 方法 / Alembic `20261105_13`。


范围：FastAPI 全部路由 × 移动端真实调用 × Feature-API-Mapping v1.0 / TechSpec v2.1 / Assistant-Runtime v1.0。

## 审查结论

- 审查开始时 OpenAPI 共 **72 个路径**，移动端实际调用 **39 个**；39 个调用全部有后端实现，不存在“前端按钮调不到接口”的断链。
- 对照 v1.0 功能映射，发现一批**有数据、但未暴露或漏实现**的接口；本次新增 **20 个路径 / 25 个方法**，OpenAPI 变为 **92 个路径 / 105 个方法**。
- 同时修复了 3 个已有接口的实质缺口：周报对注销账号泄露数据、`/me/export` 导出不完整、`/analysis-log` 不支持按比赛过滤且 limit 未限幅。

## 新增接口

| API | 作用 | 数据来源 |
|---|---|---|
| `GET /matches?date=&status=&league=` | F22 比赛目录/分类筛选 | sp_matches + 最新 verdict |
| `GET /verdicts/today?date=` | 当日全部判决目录 | verdicts |
| `GET /matches/{id}/cost?pool=` | 真实成本：Σ(1/SP)、抽水、去水概率、公平赔率、每 100 元成本 | sp_snapshots |
| `GET /matches/{id}/evidence?date=` | 比赛级判断依据（复用判决 evidence） | verdict.payload.evidence |
| `GET /matches/{id}/live` | 实况卡：已同步赛果 + SP 快照时间线；无实时源时 `live_feed=false` | match_results / sp_snapshots |
| `GET /avoid-list?date=` | 避雷榜（与 stream.avoid 同一死因口径） | verdicts.gates |
| `GET /water-rank?date=` | 水位榜：抽水最浅场次 | verdicts.rake |
| `GET /calendar?month=` | 日历：每日场次/判决/三态计数 | sp_matches / verdicts |
| `GET /sp/movements?date=` | SP 异动：同日同场同玩法最近两次快照差 | sp_snapshots |
| `GET /agents/sentinel/feed` | 盘口哨兵事件流 | events |
| `GET /me/comfort` | 买后安抚卡：最近一注的真实状态与下一步 | bets + verdicts |
| `POST /verdicts/{id}/react` | 旧契约兼容：bet/watch/disagree/not_interested；反馈写 UserEvent | bets / watch_targets / user_events |
| `POST /share/card` | 统一分享入口（verdict/weekly/streak 分发） | share_cards |
| `POST /devices` | `/push/register` 兼容别名 | push_tokens |
| `GET|PUT /push/preferences` | `/me/notify-settings` 兼容别名 | notify_settings |
| `GET /push/health` | 本账号推送 token 数、厂商配置、dry-run 状态 | push_tokens |
| `POST|DELETE /matches/{id}/follow` | `/me/watch` 兼容别名 | watch_targets |
| `GET|POST /memories`、`DELETE /memories/{key}` | `/me/memories` 兼容别名 | memories |
| `PATCH /me/persona` | 兼容 TechSpec 人设路径 | users.persona |

所有新增接口都带 `response_model`（Pydantic），并补了契约/端到端测试。

## 已有接口修复

1. **`/weekly-report` 注销账号泄露**：原来直接 `user_from_token` 后返回个人 P&L，注销冷静期也能看；现在与 `/me` 一样返回 410。
2. **`/me/export` 不完整**：补 watch_targets、notifications、notify_settings、push_tokens 元数据、user_events、完整 memories、分享 payload、注单 `sp`；推送 token/设备 token 原值仍不导出。
3. **`/analysis-log`**：支持 `match_id` 过滤，`limit` 限制 1–500，日期非法返回 422。
4. **避雷死因口径**：`stream.avoid` 与 `/avoid-list` 共用 `messaging.avoid_reason()`，避免两处逻辑漂移。
5. **新接口路由顺序**：catalog router 在 api router 之前注册，保证 `/verdicts/today` 不被 `/verdicts/{verdict_id}` 抢先匹配。
