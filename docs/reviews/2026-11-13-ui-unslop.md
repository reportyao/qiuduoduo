# 2026-11-13 UI Unslop 重构

## Direction

- **Product**：给中国竞彩用户看的 AI 赛前预测与赛后复盘台。
- **Character**：calm, exact, quietly warm.
- **World**：matchday programme / 球场记分牌：暖纸、墨绿、琥珀。
- **Moments**：预测主卡的方向与概率条；25 维预测的概率分布网格；赛后复盘比分卡。
- **Signature**：三档概率条 / 概率格，预测项墨绿、实际项琥珀，所有页面统一。

## Audit（改造前）

- 正文 14、说明 11，移动端偏小；标题层级靠字号堆叠，缺少留白。
- 「全部预测」是 25 段 `label + 一行文字`，正确比分把 19 个比分塞成一段，阅读成本高。
- 卡片统一 12px 内边距、白底细框，列表像表格堆叠。
- 预测主卡重复“方向 + 概率”与“抽水 + 阈值”两段文案，信息密度高但没有重点。
- 市场只有 3 类，且每类以一行文字拼接，价格/概率难扫。
- H5 桌面打开时引导/未成年/暂停页没有移动端最大宽度。

## 改动

1. **Spacing**：4/8/12/16/20/24/32/40 节奏；页面边距 20，卡片 24，列表/导航同一高度。
2. **Color**：保留暖纸 + 墨绿品牌；surface 更暖，line 更轻，新增 `dangerAccent` 供深色卡使用；深色只出现在预测/战绩主卡。
3. **Type**：display 34 / h1 28 / h2 23 / h3 18 / body 16 / small 14 / caption 12；行高同步放大；底部 Tab 12。
4. **Prediction**：
   - 新增 `ProbabilityBreakdown`：≤4 个结果用堆叠条+图例，>4 个结果用 3 列概率格；预测项绿、实际项琥珀。
   - 25 维预测从文字行改为概率条/网格；正确比分 19 桶全部展示。
   - 市场从 3 类扩到 11 类，并改为响应式卡片（手机 1 列、宽屏 2 列）。
5. **Cards**：预测战绩改为“比分 + 主预测 + 概率 + 实际”四段；计划页主卡改深色；引导/未成年/暂停页限制 430 宽。
6. **Copy**：删掉重复的方向/概率句，只留抽水/阈值；缩短说明，避免一句话堆满两行。
7. **Details**：概率条统一 9px 高、6px 图例点；卡片圆角 20、按钮 14、面板 26；底部安全区统一。
8. **H5**：同一套组件导出 `/h5/`，手机宽度预览与 App 一致。

## P0 落地（2026-11-14）

- 首页新增 `TodayBriefCard`：场次 / 有预测 / 已发布 / 在售、下一场倒计时、重点场次直达。
- 详情页新增 `DetailSectionTabs`：概览 / 预测 / 市场 / 复盘，长滚动拆成工作台。
- 25 维预测新增 `PredictionGroupBoard`：按主流、大小球、半场、角球、正确比分分组，默认只展开前两组。
- 市场对照增加“分歧 xx pp”，模型与市场最大差值一眼可见。
- 即时页空态显示下一场倒计时，不再只有“等待开赛”。
