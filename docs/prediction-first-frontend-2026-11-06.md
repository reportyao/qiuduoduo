# 预测优先的前端改版（2026-11-06）

## 口径

**取消“不预测”底线。** 球多多现在明确做赛前预测：给出预测方向、预测概率、置信度、成立条件与失效条件，再把抽水、市场分歧和组合成本摊开。

仍然保留的边界：

- 不承诺结果；不使用“精准预测 / 必中 / 稳赚 / 包赢”等承诺性话术。
- 概率必须带区间或校准口径，不能只给裸数字。
- 预测必须经过 AI 复核后才能发布；未发布内容不能当推荐展示。
- 预测有误差：单场可能落在少数侧，连错是正常统计现象。

## 前端信息层级

```text
首页
├─ 今日预测（已发布 snapshot 优先）
│   ├─ 预测方向
│   ├─ 预测概率 / 置信度
│   ├─ AI 复核 · 已发布
│   ├─ 成立条件 / 失效条件
│   └─ 三关（价 / 市 / 模）
├─ 今日扫描：扫描 / 通过三关 / 已发布预测 / 在售
├─ 未发布提示：有通过三关但未发布时，明确给出“看为什么”
├─ 没给预测的场次及原因
└─ 复盘、未采纳复盘、数据状态
```

## 已改动

### 首页与发布卡

- 助理开场从“算账/复核”改为“今日预测”：扫描场次、通过三关、已发布预测、在售四项分开显示。
- 底部 Tab 由“首页”改为“预测”，图标改为分析图标；发布卡标题改为“今日预测”，选择改为“预测”，模型置信改为“预测概率”，发布状态改为“已发布预测”。
- 明确区分“通过三关”和“已发布”：通过三关不等于发布，避免把 raw verdict 当推荐。
- 无 published 时不再只显示空态，显示“有 N 场通过三关，但今天还没有发布预测 · 看为什么”。

### 详情

- “完整账”改为“完整预测”；“选择/暂不选择”改为“预测/暂不预测”；“模型置信”改为“预测概率”。
- 状态改为“三关通过 / 预测复核中 / 本期不预测”。
- 三关明细按真实字段展示：市闸显示来源数与离散/阈值，模闸显示收缩后最高概率、可推线与引擎来源。
- 保留封存时间、数据截止、预测误差说明；概率不是承诺。

### 助理

- 快捷问题改为：今日预测 / 为什么不出 / 复盘 / 记住我的主队。
- 助理只回答“已发布预测”；无发布时说“还没有已发布的预测”，不再用 raw promoted 充当推荐。
- 聊天卡“今日结论/死因”改为“今日预测/未出原因”。

### 工具与记录

- “串关体检”入口改为“串关参谋”，主模式“帮我配”、次模式“自己体检”。
- 公开账本、周报、通知、关注、收件箱统一使用预测用语；“已砍”在用户主路径改为“未给预测”。
- 关于页从“不预测，只算账”改为“赛前预测，有依据”；服务说明、入模引导、AI 说明同步。

## 仍未完成

- 生产 `/recommendations/today` 仍为空，需在 `/admin` 查看 `review_runs` 失败层与发布门。
- 付费墙/权益、临场更新提醒、真实推送客户端仍未做。
- 自动生成的组合仍以 preview 为主，正式发布需走推荐主链。
- 当前赛季积分榜、部分阵容数据仍受数据源限制；未覆盖维度继续明确显示，不补编。
