# 球多多前端 Unslop 审计与改版（2026-11-06）

## 方向

- **产品**：给竞彩用户做赛前预测，给出方向、概率、条件与失效条件。
- **性格**：冷静、精确、略带温度。
- **世界**：夜里的赛前笔记本——纸张、墨绿笔迹、清晰的数字。
- **高光时刻**：已发布预测主卡（深墨绿、概率条、三关轨）；封存哈希与账本。
- **签名细节**：细三关轨（价 / 市 / 模）与等宽数字，反复出现在预测卡、详情和工具结果里。

## 审计结论

这是 **light slop**：品牌、配色和内容结构已经成立，不需要换风格。问题集中在节奏、层级、过度使用绿色装饰、重复标题、状态胶囊和少量文案。

## 全局改动

- 页面边距 18 → 20；卡片内边距 16 → 20；卡片圆角 20 → 16；主卡圆角 26 → 24。
- 标题字重 700 → 600；overline 字距 0.6 → 0.2；数字统一 tabular-nums。
- muted / subtle / amber 提高对比度，满足 4.5:1 左右的可读性。
- Tab 高 58 → 56，输入条 58 → 56；Tab badge 9 → 10。
- 设置行图标从绿色改为 muted；不再让每一行都带一个绿色图标。
- 移除悬浮头像的无限上下浮动；保留滚动/弹层收起。
- Toast 从 spring 改为 180ms timing。
- 短标题去掉句号；不再重复 Header 标题和正文大标题。
