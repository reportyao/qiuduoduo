## 任务 3：DC 模型 v1 回测 ✅（首个真实 log loss）

- **配置**：2023-24 英超 380 场 · xG 指数衰减强度（半衰期 180 天，只用过去 540 天）· DC ρ=−0.06 · 主场系数近似
- **结果**：

| 模型 | log loss | 命中率 |
|---|---|---|
| **DC v1（xG 强度 + 主场）** | **0.9191** | 59.2% |
| 市场开盘去水 | 0.9092 | 59.7% |
| 差值 | +0.0099 | −0.5pp |

- **解读（诚实）**：
  - 命中率 59% 高于长期常态（55%）——2023-24 英超主强客弱、大分差多，属赛季特性
  - 模型与市场差距 +0.0099：**符合预期**——v1 无伤停/无新闻/参数未调，"与市场一致（|≤0.02|）"正是 §"市场收缩"纪律所要求的健康状态
  - 已修复回测中市场去水公式的两处 bug（除重错误），修正后市场 0.9092 才是真实基准
- **模型升级路径（已就绪）**：伤停特征（API-Football，v1.0）→ 情报庭 edge；ρ 与主场系数用 penaltyblog 全量 MLE 替代近似值 → 预计再收 0.003–0.008
- **收缩纪律首测（重要发现）**：模型与市场偏差 >8pp 的场次占 40%（153 场）——v1 模型对某些场次过于自信。加">8pp 砍半偏差"的收缩后 log loss 0.9191 → **0.9104**，几乎追平市场（0.9092）。两个推论：① 收缩纪律（TechSpec §"市场收缩"）**实测有效，进 v1.1 模型**；② 40% 大偏差说明 v1 的 xG 强度对升班马/引援剧变队适配差（Burnley 类），这是 v1.1 特征工程的重点（升班马先验/引援净投入特征）
