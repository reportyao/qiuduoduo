# 球多多 · UI 静态演示版（旧，仅设计参考）

按 PRD v5.1 实现的全功能可点击原型（单文件 HTML，零依赖，手机/电脑浏览器通吃）。

## 打开方式

- **电脑**：双击 `index.html`，或本地起静态服务后访问 `http://127.0.0.1:8823/index.html`
- **手机**：同一 WiFi 下访问 `http://<你电脑的IP>:8823/index.html`，或直接把 `index.html` 发到手机用浏览器打开
- 数据存于浏览器 localStorage；想重置为新用户：地址栏加 `?cb=1` 或清除站点数据

## 建议体验路线（10 分钟）

1. **首启链路**：年龄门 → 价值页 → 第一个判决 → 通知软请求（点"好"）
2. **买了全流程**：点「买了」→ 触发登录页（手机/验证码随便填，点"登录/注册"）→ **自动回到金额确认**（回跳不断链）→ chips 选金额 → 复制出票文案 → 记下了（卡变"已记 ✓"）
3. **为什么/不同意**：详情页看概率分布、判断依据（点条目展开来源）、三关、价差、反方；流里点「不同意」看 AI 摆数据不建议顺从
4. **串关体检旗舰**：流顶绿色横幅 → 勾腿/定金额 → 核算序列动画 → 健康分 38 + 发现四层 + 附录 A → 方案对比 → 按方案 C 出单（3 注拆单文案复制）
5. **实况卡**：流里哨兵卡点进去 → LIVE 67' · 走盘教学 · "更新 6 次只推送 1 次" · 进球提醒开关
6. **人设切换**：我的 → 助理人设 → 切"感性老炮"或"元气搭子" → 回流看判决文案实时变化（数字不变）
7. **今日在售**：顶部状态条 → 体彩同步列表 + 筛选 + 凌晨场停售认知差
8. **其他**：相机按钮（拍票记账 / 截图鉴别）/ 功能面板"+"（水位榜等）/ 我的（赔率格式四制切换、语言、订阅、合规中心自排除）
9. **演示空态**：功能面板最后一项"切换空态"（演示版内置于面板）

## 已实现的真实交互

- 路由栈 + 返回、弹层、Toast、触觉震动（手机上）
- localStorage 持久化（登录态/人设/票单/关注/自排除）
- 买了→登录→**回跳继续**（不断链）
- 撤销 5 秒、出票文案一键复制
- 人设热切换（判决/复盘/安抚/空态四类文案随人设变）
- 自排除生效后拦截购买并显示热线
- 赔率四格式换算（欧/港/印尼/美式）
- JSON 数据导出下载

## 与正式版的关系

这是 PRD v5.1 的 UI 交互基准（历史设计验证）。**当前实现规格以 `apps/mobile/` 为准**；本页仅作设计参考，不再加功能。
