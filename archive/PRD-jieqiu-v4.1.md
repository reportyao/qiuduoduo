## 新增 §7 触达与通知策略（重写，替代 v4.0 §4.1 推送段落）

### 7.1 前提事实（2026 微信生态）

- 服务号**模板消息**处于下线通道；**订阅消息**为"一次授权收一条"，长期订阅类目不含博彩数据分析
- 结论：**CN 微信生态内不存在可规模化的每日主动推送**
- 短信 ¥0.045/条 → 10 万 DAU 日推 ¥13.5 万/月，仅保留给付费用户关键事件

### 7.2 触达分层

| 层 | 内容 | CN 通道 | Global 通道 | 频控 |
|---|---|---|---|---|
| **追人层** | 预算拦截、连败保护、自排除生效、支付凭证 | 企微 1v1 / 短信（付费用户） | Web Push / Email | 事件驱动，≤2 条/日 |
| **轻推层** | "判决已出"信号 | 企微群/服务号订阅消息（用户主动授权多少发多少） | Web Push | ≤1 条/日 |
| **拉取层** | 判决流全部内容 | H5 打开（PWA 快捷方式） | PWA 打开 | 不限 |
| **回访层** | 周报、复盘摘要 | Email（CN 可用性一般，辅助） | Email | ≤2 条/周 |

### 7.3 习惯养成机制（拉取层的设计核心）

| 机制 | 设计 |
|---|---|
| 快捷方式引导 | 首次采纳判决后引导"添加到桌面"（PWA），完成率目标 ≥25% |
| 时间锚点 | 判决固定 19:02 发布（错峰推送后用户侧仍感知"19 点看解球"） |
| 连续采纳周 | 替代签到：连续 N 周有采纳 → 解锁历史数据导出等软权益 |
| 锁屏/小组件 | M3 原生 App 后提供当日判决小组件 |

### 7.4 指标修正

| 旧指标 | 新指标 |
|---|---|
| 推送打开率 ≥15% | **习惯打开率**：19:00–20:00 主动打开用户占比，目标 ≥30%（M2） |
| 推送到达率 ≥95% | 按渠道分别设定：企微 ≥90%、Web Push ≥75%、Email 打开 ≥25% |
| 新增 | 快捷方式安装率 ≥25%（30 日内新用户） |

## 新增 §11 运营与内容安全

| 模块 | 要求 |
|---|---|
| 内容审核 | 截图鉴别的上传图、聊天输入：审核 API + 敏感词双通道；命中拦截并提示 |
| UGC 责任 | 用户输入不留存原文超过 30 天（脱敏后仅保留审核标记） |
| 工单与申诉 | 站内工单；对拦截/风控判定可申诉，48h 内人工复核 |
| 举报 | 判决/分享卡/聊天可举报，进入 moderation 队列 |
| 客服 | M1 人工（企微），M2 帮助中心 + AI 客服兜底（人工优先） |

## 新增 §12 防滥用与风控

| 风险 | 对策 |
|---|---|
| ¥9.9 试用薅羊毛 | 设备指纹 + 同设备账号数限制 + 支付方式去重 |
| 付费数据被爬 | 成本标签等免费接口限速；字段级水印（可溯源泄露源） |
| 账号盗用 | 异地登录提醒 + refresh 复用检测强制下线 |
| B 端滥用 | API 配额分层（M3） |

## 新增 §13 各阶段转向条件（pivot gates）

| 阶段 | 检验 | 不通过的转向 |
|---|---|---|
| v0.5 | 三数验证（抽水离散度等） | 闸一失效 → 换过滤条件；全不通过 → 产品转"纯纪律+成本工具" |
| v1.0 | 内测 WAV ≥1.0/人/周 | <0.8 → 判断不可信，回炉模型，暂停扩量 |
| v1.5 | 付费转化 ≥3% | <2% → 重审价值主张与定价，不进全球版 |
| v2.0 | 30 天留存 ≥10% 且 CLV>0 | CLV≤0 连续 2 月 → 收缩到 B 端与效率定位 |
| v2.5 | B 端 beta ≥5 家付费 | <3 家 → B 端延后，专注 C 端订阅 |
