## 1. 产品定位与全球市场

### 1.1 一句话定位

> 每天用一句话告诉你"买什么、别买什么、花多少"的 AI 竞彩助理。前台极简，后台完整，一切可审计。

### 1.2 市场分层

| 阶段 | 市场 | 玩法体系 | 关键差异 |
|---|---|---|---|
| **M1（0–3 月）** | 中国大陆竞彩 | 竞彩官方 SP、整数让球、单关/串关 | 合规最严：只做数据分析工具，不碰售彩 |
| **M2（3–6 月）** | 全球英语区（英/东南亚/拉美起步） | 亚盘/欧赔、交易所、多庄家 | Betfair 类交易所当公允价，Stripe 收款 |
| **M3（6 月+）** | 扩展语种（西/葡/越/日/泰/印尼） | 同 M2 | 本地支付与合规包逐个接入 |

### 1.3 每市场 edge 论点（可插拔架构的产品前提）

UI（三道闸、成分标签、账本）全球通用；**"edge 从哪来"按市场配置**：

| 市场 | 价格源 | edge 论点 |
|---|---|---|
| 中国竞彩 | 官方 SP + Pinnacle | 官方调价滞后 + 整数让球结构性偏差 |
| 英国 | Betfair 交易所 + 庄家 | 交易所价差、庄家间离散 |
| 美国/全球 | 多庄家比价 | 庄家间定价离散、开收盘漂移 |

**工程要求：edge 论点 = 配置模块，不是写死的代码。**

### 1.4 北极星

**每周被采纳的判决数（WAV）**——用户点"买了"且赛后确认的判决数。辅助指标按市场分维度看。

### 1.5 产品原则（v4.0 修订版）

| # | 原则 | 说明 |
|---|---|---|
| 1 | 判决流是唯一主界面 | 无 Tab 堆砌，流内五类消息 |
| 2 | 三个交互原语 | 买了 / 为什么 / 不同意 |
| 3 | 主动但克制 | 每日推送 ≤ 4 条，连败照发 |
| 4 | 记忆可见可改 | 口述 > 推断，禁止用于营销恐吓 |
| 5 | 没把握就明说 | 无推荐日发教育内容，禁止凑数 |
| 6 | **表面可供性（新增）** | 豆包式四层入口：话术 chips / 输入栏动作 / 功能面板 / 助手人格化。用户永远知道下一步能干嘛 |
| 7 | **"我的"为辅（修订）** | v2.0 的"无设置页"修正为：设置收敛到一个"我的"页，入口两处（顶栏头像 + 功能面板）。账户体系与全球化需要锚点，参考豆包同样保留"我的" |
| 8 | 合规即 UX | LegalSlot 每页必有，内容按 locale 注入 |

## 2. 用户与账户体系

### 2.1 用户分层（全球版）

| 层 | 画像 | 付费 |
|---|---|---|
| 初级玩家（基本盘） | 每周 2–3 次、30 秒决策、微信/WhatsApp 生态 | ¥29 / $4.99 月 |
| 进阶玩家 | 懂盘口、要概率区间与对账 | ¥199 / $29.99 月 |
| B 端（博主/店主） | 要内容产能与白标 | ¥1500+ / $99+ 月 |

### 2.2 匿名优先原则

**不注册也能用：** 看判决流、成分标签、避雷榜、公开账本。
**注册触发点（只在这些时刻要求）：**

| 触点 | 原因 |
|---|---|
| 点"买了"记账 | 跨会话保存票单 |
| 设置预算/开启守护 | 数据持久化 |
| 接收推送 | 需要联系方式 |
| 订阅付费 | 支付实名 |
| 换设备同步 | 账号绑定 |

### 2.3 登录方式（分区域）

| 区域 | 主方式 | 备用方式 | 说明 |
|---|---|---|---|
| 中国大陆 | 手机号 + 短信验证码 | 微信一键授权（微信内 H5 自动带出） | 模板消息依赖微信身份 |
| 全球 | Google / Apple（iOS 上架必需） | Email + 验证码（magic code） | 不做密码，防撞库 |

### 2.4 年龄门

| 市场 | 年龄 | 实现 |
|---|---|---|
| 中国大陆 / 英国 / 大多数 | 18+ | 首次启动自声明出生年份 + 勾选确认 |
| 美国部分州 | 21+ | 按州配置（market profile） |
| 进阶（M2 后期） | 证件核验 | 接第三方 KYC（如 Sumsub），仅在合规要求时启用 |

**未通过年龄门 = 只能看公开账本页，不能看判决流。**

### 2.5 账号状态机

```
匿名(device_id) → 已注册 → 已订阅 → 〔自排除/cool-off〕→ 注销(7天冷静期)
                     ↓ 违规封禁
```

## 4. 核心功能规格（v4.0 定稿）

### 4.1 判决流

流内五类消息：主推判决（12:30 付费/赛前 2h 免费）、避雷榜（12:30）、预算与拦截（触发式）、赛后归因（次日 10:00）、对话回复（不限）。**每日推送 ≤ 4 条。**

**四层入口（豆包式可供性）：**

| 层 | 内容 | 位置 |
|---|---|---|
| 话术层 | "你可以这样说" + 5 个建议词 chips（轮换：今晚买啥/这场能买吗/查：曼城/改预算 50/它记得我什么） | 输入框上方常驻 |
| 动作层 | + 功能面板 / 截图鉴别 / 语音 | 输入栏两侧圆钮 |
| 功能层 | 快捷入口条（水位榜/我的票单/账本/预算） | 流顶部 |
| 能力层 | 4 个智能助手卡（含实时状态行） | `/agents` + 流内首次引导 |

### 4.2 三道闸（机制不变，阈值可配置）

```
47 场 → 闸一「价」抽水>12% 淘汰 → 闸二「市」四家分歧>阈值 淘汰 → 闸三「模」信息不全 淘汰 → 终审（模型×市场×资金动向排序）
```

硬规则：三关全过才有推荐；无推荐日发"今晚没有值得买的"+教育内容；每关淘汰明细在"为什么"L3 可见。

### 4.3 判决卡（P0-1 减负定稿）

默认层只显示：对阵/玩法结论、置信仪表（A/B/C + 分数）、"市场少算 X.Xpp"判语、三关一行 chips、一句话理由、三个按钮、封存行。
下沉进"为什么"：概率对齐条、资金信号、三庭明细、淘汰明细、完整证据链。

### 4.4 买了流程（新增完整规格）

```
点「买了」
  → 内联展开：金额 chips（20/50/100/自定义）+ 「去出票」
  → 确认后记录：票单 + 当时 SP + 时间戳（可 5 秒内撤销）
  → 反馈："记下了。赛后我告诉你对不对。"
```

- **官方场次编号必显**：判决卡带"周三012"，提供一键复制文案 `周三012 让球主胜(-1) @2.05`——用户去实体店/官方渠道可直接使用
- 不记金额可选（标记"未记账"，不进预算统计但进 CLV 统计）
- 预算超支时触发拦截（见 4.6）

### 4.5 成分标签 / 避雷榜 / 空状态

- 成分标签免费：抽水率（进度条对比今日最深）、四家分歧度、散户情绪、每 100 元期望回报、今日水位排名。正向话术："随便买约玩 9 注，挑着买约玩 14 注"
- 避雷榜四类判定：信息不足/价值为负/高波动/冷门陷阱
- **空状态教育版（P1 修订）**：无 edge 日不再推"水最浅 3 场"（与纪律冲突），改推"今日课程"（如：为什么抽水 13.4% 的场次长期必亏）

### 4.6 预算守护 + 连败保护（新增）

| 规则 | 内容 |
|---|---|
| 预算 | 周预算，80%/100% 两级提醒，只陈述事实 |
| 追损拦截 | 同晚连亏 2 单后再买 → 琥珀卡："这个时候的手，最容易出错" |
| 深夜提醒 | 23:30 后提示"明天再看"（按用户本地时区） |
| **连败保护（新增）** | 连败 ≥3 场自动切观望模式：只发避雷与复盘，不发新推荐；恢复条件：用户手动或 72h 后 |

### 4.7 赛后归因

三分类：信息不足 / 模型偏差 / 随机波动。每次错误附"AI 已学"动作（如：门将临场变动 → 加入抓取清单）。月度占比公示，模型偏差 > 30% 触发复审。

### 4.8 记忆系统

类型：预算/偏好/历史/承诺/态度。规则：口述 > 推断；推断 90 天未强化衰减；**冲突处理（新增）：两条记忆矛盾时，当场问一句"听哪条？"，答案写入记忆**。可见可删（`/me/memories`）。

### 4.9 智能助手（引擎人格化）

| 助手 | 后台引擎 | 状态行示例 |
|---|---|---|
| 盘口哨兵 | 资金信号监测 | "今日已捕获 3 次" |
| 成本计算器 | overround + 期望计算 | "本周被使用 128 次" |
| 复盘教练 | 归因系统 | "今晚 22:00 等你" |
| 纪律管家 | 预算+拦截 | "本周已拦截 2 次" |

定位：**不是功能广场，是后台引擎的人格化**——平时主动提醒（AI 原生），点进去可对话（豆包式）。M1 先上"成本计算器+纪律管家"，盘口哨兵事实版 M1.5，预测版 V2。

### 4.10 信任系统

赛前封存（哈希+时间戳，变更生成新版本并双公示）、赛后自动结算、公开账本（含最差月份与连败纪录）、模型周报。**初级展示名"AI 眼光分"（=CLV），进阶显示 CLV。**

### 4.11 功能优化项（本期确认纳入）

| 功能 | 规格 | 版本 |
|---|---|---|
| 确定度日历 | 月视图按分歧度均值着色，"哪天好猜" | M2 |
| SP 变动提醒 | 关注场次 SP 涨跌推送，含停售倒计时 | M1.5 |
| 冷门指数 | 爆冷概率+历史同类频率，只放信息区不放推荐区，过校准 | M2 |
| 模型周报 | 每周五：改动/校准/与市场对打记录 | M2 |

## 5. 账户与设置页规格（新增，逐页）

### 5.1 年龄门 `/gate`

- 元素：产品一句话 + 市场自动检测提示（"检测到你在〔地区〕，使用〔竞彩/国际盘〕数据"）+ 出生年份选择 + 合规确认勾选
- 规则：年份 < 法定年龄 → 显示当地帮助资源（helpline），拒绝进入；不存储精确生日，只存 `age_verified: true + 阈值版本`
- 可跳过？不可。可"只看公开账本"（未验证状态）

### 5.2 登录/注册 `/auth/login`

**中国大陆：**
```
[ 手机号输入 ] [ 获取验证码 ]
[ 验证码输入 ] [ 登录/注册 ]
── 微信一键登录（微信内显示）──
```
**全球：**
```
[ 继续 Google ] [ 继续 Apple ]
── 或 ──
[ Email ] [ 发送登录码 ]
```
- 验证码 6 位，10 分钟有效，60s 重发限制；同一 IP 限 5 次/小时
- 新注册即注册（无独立注册页）；登录即同意条款（勾选 + 条件链接）
- 错误态：验证码错（剩 N 次）/ 频率限制 / 网络失败，均给下一步动作
- 页脚：语言快速切换（见 6.3）+ LegalSlot

### 5.3 我的 `/me`（设置中心锚点）

```
头像/昵称 · 订阅状态徽章 · 市场徽章（中国竞彩）
──────────────
账号与安全    手机/邮箱 · 设备管理 · 注销
偏好          语言 · 地区/市场 · 时区 · 赔率格式 · 货币 · 关注联赛
通知          分类型开关 · 免打扰时段
纪律          预算 · 追损保护 · 连败保护 · 合规中心
数据          我的票单 · 记忆管理 · 个人 alpha · 数据导出
会员          订阅管理 · 恢复购买
关于          公开账本 · 模型周报 · 用户协议 · 隐私政策 · 帮助
──────────────
LegalSlot（当地法定文案 + helpline）
```

入口：顶栏头像 + 功能面板。**判定标准：任何设置 2 步内可达。**

### 5.4 偏好设置 `/me/preferences`（全球化核心页）

| 设置项 | 取值 | 存储与生效 |
|---|---|---|
| **界面语言** | 跟随系统 / zh-CN / en / ... | 立即生效，路由 `/{locale}` 切换 |
| **内容语言** | 同界面 / 单独选 | 判决书按此语言生成 |
| 地区/市场 | 中国竞彩 / 国际盘 | 切换需二次确认（数据源与玩法不同）；记入 market profile |
| 时区 | 自动（定位）/ 手动 | 展示层时区，引擎存 UTC |
| **赔率格式** | 欧赔 1.85 / 香港盘 0.85 / 印尼盘 -1.17 / 美式 +150 | 存储恒为欧赔，展示层转换 |
| 货币显示 | CNY / USD / EUR / 仅用"单位" | 仅影响显示；投注建议默认"单位制"避免汇率噪音 |
| 关注联赛 | 多选 | 决定流内出现哪些联赛（不含博彩推荐范围） |

### 5.5 通知设置 `/me/notifications`

分类型开关：主推判决 / 避雷榜 / SP 变动 / 赛后复盘 / 预算拦截（默认开，建议不可关，标注"为什么"）。免打扰时段（默认 23:30–08:00 本地时区，预算拦截除外）。渠道跟随区域：微信模板消息 / Web Push / Email。

### 5.6 合规中心 `/me/compliance`（新增，监管硬要求）

| 功能 | 规格 |
|---|---|
| 存款/投入限额 | 日/周/月上限，调低立即生效，调高冷却 24h |
| 自我评估 | PGSI 量表（9 题），结果分级给建议 |
| **自排除 Cool-off** | 24h / 7 天 / 30 天 / 永久；生效期间不可看判决流、不可记账；永久自排除不可撤销 |
| Helpline | 页面固定显示当地热线（CN 无强制，UK BeGambleAware，US 州热线） |
| 现实核查 | 可选：显示累计投入 vs 累计回报 |

### 5.7 会员订阅 `/me/subscription`

| 区域 | 方案 | 价格 |
|---|---|---|
| CN | 会员 / 专业 | ¥29 / ¥199 月，首月 ¥9.9 |
| 全球 | Member / Pro | $4.99 / $29.99 月，7 天试用 |

价值主张唯一版式：**时间门控**（付费 12:30 可见 vs 免费赛前 2h）。免费墙页：结论区打码 + "已过三关·置信 A"可见 + 两个按钮（¥29 解锁 / 先看战绩）。
订阅状态机：trial → active → past_due（3 次重试）→ canceled。恢复购买（App Store/Stripe）。

### 5.8 数据与隐私 `/me/privacy`

- 导出：JSON 全量（票单/记忆/设置），24h 内生成，下载链接 72h 有效
- 注销：二次确认 → 7 天冷静期（可撤回）→ 匿名化删除；票据与账本公示数据按法规保留（脱敏）
- 同意管理：条款版本记录，营销类同意可单独撤回

## 6. 多语言与全球化规格（新增）

### 6.1 语言范围

| 阶段 | 语言 |
|---|---|
| L1（M1） | zh-CN |
| L1.5（M1.5） | + en（全球英语区统一 en，不做 en-GB 差异化） |
| L2（M2+）队列 | es、pt-BR、vi、ja、th、id |

### 6.2 三语言解耦（关键设计）

| 层 | 是什么 | 例子 |
|---|---|---|
| UI 语言 | 界面文案 | "今晚没有值得买的" |
| 内容语言 | 判决书/复盘/避雷理由 | LLM 按内容语言生成 |
| 数据语言 | 球队/联赛名 | 映射表本地化（曼城/Man City/曼彻斯特城） |

三者默认一致，可分别设置（进阶用户可能 UI 英文 + 内容中文）。

### 6.3 语言切换交互（3 处入口）

1. **首次启动**：读系统语言自动选，年龄门页可改
2. **登录页页脚**：快速切换（未登录用户的唯一设置入口）
3. **我的 > 偏好 > 界面语言**：全量切换

切换即时生效（路由 `/{locale}` 重渲染），无需重启；切换后弹确认："内容语言也切换为 English 吗？"

### 6.4 术语表制度（禁止机翻领域词）

| 中文 | English | 备注 |
|---|---|---|
| 让球 | handicap | |
| 串关 | UK: accumulator / US: parlay | 按 market profile 选词 |
| 水位 / 抽水 | odds movement / bookmaker margin | |
| 单关 | single | |
| 停售 | cutoff | |
| 四家分歧 | cross-book divergence | |
| 成分标签 | cost label | 产品名，保留不译意 |
| 判决 | verdict | |
| 封存 | sealed | |
| 看好度→置信 | confidence grade | |

制度：`glossary` 表维护（locale, source, target, domain）；LLM 生成后跑术语校验，命中禁用/错误术语即重写。

### 6.5 文案规范

- 所有按钮/标签按英文 +30% 长度设计，禁止固定宽度；CJK 不加粗号
- ICU MessageFormat 处理复数/性别（"N 场被砍" → `{count, plural, one {# match} other {# matches}}`）
- 数字一律走 Intl.NumberFormat；负号用 hyphen-minus 渲染（规避 U+2212 字形缺失）；百分号位置按 locale
- 语气规范 per locale：中文"懂行的朋友"；英文"witty quant friend"，禁翻译腔

### 6.6 时间 / 货币 / 赔率

| 项 | 规范 |
|---|---|
| 时间四件套 | 绝对（11月2日 03:30）+ 相对（明晨）+ 时区标注 + 停售倒计时；展示用用户时区，引擎 UTC；推送定在**本地** 19:00 |
| 货币 | 显示层转换（每日汇率任务）；投注建议默认"单位制" |
| 赔率格式 | 存储恒为欧赔小数；四种展示格式按用户设置转换 |

### 6.7 LegalSlot（每页底部固定插槽）

| Locale | 内容 |
|---|---|
| zh-CN | "数据分析结果，不构成投注建议。未满 18 周岁禁止购买彩票。" |
| en-UK | "18+ | BeGambleAware.org | Gamble responsibly." |
| en-US | "Problem gambling? Call 1-800-GAMBLER. {state} law applies. 21+ in some states." |
| de | "Glücksspiel kann süchtig machen. Hilfe: check-dein-spiel.de" |

工程实现为 `<LegalSlot market="CN"/>`，内容来自 market profile 配置，**产品文案不可覆盖它**。

### 6.8 LLM 多语言判决生成

同一结构化 payload（数字已在白名单内）→ 按 content_locale 选择 prompt 模板 → 生成 → 校验（数字白名单 + 术语表 + 长度上限）→ 不合格重写（最多 2 次）→ 兜底用模板拼接（无 LLM 也能出结果）。

### 6.9 RTL 策略

v4.0 不支持阿拉伯语，但布局全部使用 CSS 逻辑属性（margin-inline 等），图表方向保持 LTR。进入中东市场时零重构。
