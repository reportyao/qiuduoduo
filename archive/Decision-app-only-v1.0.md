# 决策备忘：App-only（不做小程序）影响清单 v1.0

| 项目 | 内容 |
|---|---|
| 决策 | 产品形态 = 安卓 + iOS 原生 App（Expo 一套代码）；不做微信小程序、不做 H5 主站 |
| 保留 Web | 仅两个页面：公开账本（外链分享载体）+ 下载落地页 |
| 日期 | 2026-11-01 |
| 修订对象 | PRD v4.1、TechSpec v1.1、Roadmap v1.0 |

---

## 1. 定位不变的部分（重要确认）

- **定位手术照做**：监管针对"内容形态"（暗示命中率/稳赢话术）而非平台；App 的开屏、商店描述、推送文案、分享卡全在监管射程内
- 新华社点名的是"AI 荐彩引流"模式；**上架正规商店恰是自证清白动作**——前提是商店描述经得起审
- 核心叙事不变："我们不预测谁赢，我们算清楚这一注的成本"
- 禁用词表（红单/必中/连红/私厨/稳赢/杀庄…）适用于 App 全部文案 + 商店元数据

## 2. 触达策略重构（简化 PRD v4.1 §7）

| 层 | 原方案（H5/企微补丁） | App-only 方案 |
|---|---|---|
| 追人层 | 企微 1v1 / 短信 | **原生推送**（确定性到达） |
| 轻推层 | 订阅消息求授权 | 原生推送（≤1 条/日） |
| 拉取层 | PWA 快捷方式引导 | App 桌面图标（引导章节删除） |
| 回访层 | Email | Email + 推送摘要 |

- **删除**：习惯打开率补丁指标 → 恢复推送打开率（≥15%）；快捷方式安装率指标删除
- **新增 v1.5 功能**：锁屏小组件（iOS WidgetKit / 安卓 Glance），今日判决上锁屏
- 国内安卓推送：FCM 不可用 → **JPush 或厂商通道聚合**（华为/小米/OPPO/vivo），列入必办

## 3. 新增合规清单（时间线 > 代码）

| # | 事项 | 周期 | 启动时点 |
|---|---|---|---|
| 1 | 公司主体（备案+收单挂靠） | 2–3 周 | **W1 立即** |
| 2 | 软件著作权（可加急） | 2–4 周 | W1 |
| 3 | APP 备案（工信部，强制） | 2–4 周 | 主体下来即办 |
| 4 | ICP 备案（苹果中国区硬要求） | 与 APP 备案并行 | 同上 |
| 5 | 商店类目策略：体育/资讯/工具；名称与副标题避开"彩票/足彩/竞彩" | — | 提交前定稿 |
| 6 | App 隐私合规：隐私弹窗/SDK 清单/权限最小化 | 1 周开发 | v0.5 内 |

## 4. 技术选型修订

| 层 | 定稿 |
|---|---|
| 前端 | **Expo (React Native)**，双端一套；Web 仅账本+落地页（Next.js 静态） |
| Auth | Supabase Auth（RN SDK；手机号/Apple/Google） |
| 订阅 | **RevenueCat**（iOS IAP + 安卓支付统一层；webhook 对 FastAPI） |
| 推送 | 海外：Expo Notifications；国内：JPush 聚合厂商通道 |
| 后端 | 不变：FastAPI + penaltyblog + PostHog(RN SDK) |
| iOS 成本 | IAP 抽成 15%（Small Business）；定价：iOS 档 ¥30 或全端统一上调 |

## 5. 增长通道修订

- 删除：微信小程序裂变、PWA 快捷方式
- 保留：判决卡**图片分享**到微信（不受影响）
- 新增：ASO（商店关键词：竞彩分析/盘口/水位）、虎扑/直播吧/懂球帝社区、**店主场景**（B 端店主装机给到店彩民看）
- 红线：抖音/小红书禁彩票类营销——引流内容只讲方法论
- 免费钩子：官网 H5"今日结论先看 → 引导下载"

## 6. Roadmap 修订

| 版本 | 变更 |
|---|---|
| v0.5 | TestFlight + 安卓 APK（蒲公英）内测；W1 启动主体/软著/备案三线；商店上架不在本版 |
| v1.0 | App Store + 主流安卓商店正式上架（备案就绪为前置条件）；推送全量 |
| v1.5 | 收单：iOS IAP + 安卓微信/支付宝；锁屏小组件；RevenueCat 上线 |
| M3 | 小程序保持移除；如需再评估 |

## 7. 一句话

> App-only 不是绕开监管，是把监管前置成上架条件——定位手术照做，推送红利吃满，办证时间线比代码更急。
